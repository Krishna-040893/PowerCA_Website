# Affiliate Referral Integrated Flow

## Overview

The affiliate referral system now uses a **single integrated table** (`affiliate_referrals`) to store both the initial customer email (added by affiliate) and the full customer signup details. This ensures all referral data is in one place.

## Database Table: `affiliate_referrals`

### Key Columns

| Column                 | Type      | Description                                             |
| ---------------------- | --------- | ------------------------------------------------------- |
| `id`                   | UUID      | Primary key                                             |
| `affiliate_profile_id` | UUID      | Links to affiliate profile                              |
| `affiliate_id`         | TEXT      | Affiliate ID (e.g., AFF001)                             |
| `customer_id`          | TEXT      | Auto-generated (e.g., CUS001, CUS002)                   |
| `referred_user_id`     | UUID      | Links to `registration_forms` table (NULL until signup) |
| `referred_email`       | TEXT      | Customer email                                          |
| `referred_name`        | TEXT      | Customer name                                           |
| `referred_phone`       | TEXT      | Customer phone                                          |
| `referral_code`        | TEXT      | Affiliate's referral code                               |
| `status`               | TEXT      | pending, converted, completed, expired, cancelled       |
| `created_at`           | TIMESTAMP | When affiliate added customer                           |
| `updated_at`           | TIMESTAMP | Last update timestamp                                   |

## Complete Flow

### Step 1: Affiliate Adds Customer Email

**Location:** Affiliate Account Page

1. Affiliate logs in to their account
2. Goes to "Create Customer Referral" section
3. Enters customer email only
4. Clicks "Send Referral Link"

**What Happens:**

```sql
-- Record created in affiliate_referrals table
INSERT INTO affiliate_referrals (
  affiliate_profile_id,
  affiliate_id,
  referral_code,
  referred_email,
  customer_id,  -- Auto-generated: CUS001, CUS002, etc.
  status
) VALUES (
  '5f94c5a9-5684-46b2-8f83-fafebf366694',
  'AFF001',
  '823E545E',
  'customer@email.com',
  'CUS001',  -- Generated by trigger
  'pending'
);
```

### Step 2: Customer Receives Email

- Email sent to customer with referral link
- Link format: `https://powerca.in/pricing?ref=823E545E&cus=CUS001`
- Email contains:
  - Affiliate's name
  - Special pricing offer
  - Call to action button

### Step 3: Customer Clicks Link

- Customer redirected to pricing page with parameters:
  - `ref`: Referral code (823E545E)
  - `cus`: Customer ID (CUS001)
- Customer clicks "Sign Up" or "Get Started"

### Step 4: Customer Signs Up

**Location:** Registration Page (`/register` or `/register/student`)

1. Customer fills out signup form:
   - Name
   - Email (must match the email affiliate added)
   - Mobile number
   - Password
   - Other required fields
2. Clicks "Sign Up"

**What Happens:**

The registration API:

1. **Creates user account** in `registration_forms` table
2. **Updates existing referral record** in `affiliate_referrals` table:

```sql
-- Find the matching referral record
SELECT * FROM affiliate_referrals
WHERE referral_code = '823E545E'
  AND customer_id = 'CUS001'
  AND referred_email = 'customer@email.com';

-- Update it with full customer details
UPDATE affiliate_referrals
SET
  referred_user_id = '{{new_user_id}}',  -- Links to registration_forms
  referred_name = 'John Doe',
  referred_phone = '9876543210',
  updated_at = NOW()
WHERE id = '{{referral_record_id}}';
```

**Result:** All customer data is now in the **same record** in `affiliate_referrals` table.

## Key Benefits

### 1. **Single Source of Truth**

- All referral data in one table
- No need to join multiple tables to get complete customer info
- Easy to track referral status and customer details

### 2. **Automatic Linking**

- Customer email added by affiliate
- When customer signs up with that email, record automatically updated
- `referred_user_id` links to actual user account in `registration_forms`

### 3. **Simple Queries**

```sql
-- Get all referrals for an affiliate with full customer details
SELECT * FROM affiliate_referrals
WHERE affiliate_id = 'AFF001'
ORDER BY created_at DESC;

-- Get pending referrals (not yet signed up)
SELECT * FROM affiliate_referrals
WHERE affiliate_id = 'AFF001'
  AND referred_user_id IS NULL
  AND status = 'pending';

-- Get completed signups
SELECT * FROM affiliate_referrals
WHERE affiliate_id = 'AFF001'
  AND referred_user_id IS NOT NULL;
```

## Code Changes Made

### 1. Registration API (`src/app/api/registrations/route.ts`)

**Added:**

- Extract referral parameters (`ref` and `cus`) from request
- After creating user, find matching referral record
- Update referral record with full customer details

```typescript
// Extract referral parameters
const referralCode = body.referralCode || body.ref || null
const customerId = body.customerId || body.cus || null

// After user creation, update referral record
if (referralCode && customerId && newUser?.id) {
  const { data: referralRecord } = await supabase
    .from('affiliate_referrals')
    .select('*')
    .eq('referral_code', referralCode)
    .eq('customer_id', customerId)
    .eq('referred_email', email)
    .single()

  if (referralRecord) {
    await supabase
      .from('affiliate_referrals')
      .update({
        referred_user_id: newUser.id,
        referred_name: name,
        referred_phone: phone,
        updated_at: new Date().toISOString(),
      })
      .eq('id', referralRecord.id)
  }
}
```

### 2. Register Pages

**Updated Both:**

- `src/app/(auth)/register/page.tsx` (Professional)
- `src/app/(auth)/register/student/page.tsx` (Student)

**Added:**

- Function to extract `ref` and `cus` from URL parameters
- Include referral params in registration payload

```typescript
const getReferralParams = () => {
  // Check direct params first
  const ref = searchParams.get('ref')
  const cus = searchParams.get('cus')

  if (ref && cus) return { ref, cus }

  // Check callbackUrl params
  if (callbackUrl) {
    const url = new URL(callbackUrl, window.location.origin)
    const urlRef = url.searchParams.get('ref')
    const urlCus = url.searchParams.get('cus')
    if (urlRef && urlCus) {
      return { ref: urlRef, cus: urlCus }
    }
  }

  return { ref: null, cus: null }
}

// In form submission
const { ref, cus } = getReferralParams()
const payload = {
  ...formData,
  ...(ref && cus && { referralCode: ref, customerId: cus }),
}
```
