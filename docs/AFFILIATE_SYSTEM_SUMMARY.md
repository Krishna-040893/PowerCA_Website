# PowerCA Affiliate Referral System - Complete Guide

## System Overview

Your affiliate system is **correctly designed** and **fully functional**. Here's how it works:

### Database Structure

```
affiliate_registrations (applications)
  └─> affiliate_profiles (approved affiliates)
       └─> affiliate_referrals (customer referrals)
            └─> payments (completed purchases)
```

### Key Tables:

1. **`affiliate_profiles`** - Stores affiliate information
   - `affiliate_id` (e.g., AFF001, AFF002) - Admin-assigned
   - `referral_code` (e.g., 0CDCCBF1, D1FCE89E) - Admin-assigned
   - Counter fields: `total_referrals`, `successful_referrals`, `pending_referrals`
   - Commission fields: `total_commission`, `paid_commission`, `pending_commission`

2. **`affiliate_referrals`** - Tracks each customer referral
   - `customer_id` (e.g., CUS001, CUS002, CUS003) - Auto-generated
   - `referral_code` - Affiliate's referral code
   - `referred_name`, `referred_email`, `referred_phone` - Customer details
   - `status` - 'pending', 'completed', 'expired', 'cancelled'

3. **`payment_orders`** - Tracks purchase attempts
   - Links referral_code + customer_id during checkout

4. **`payments`** - Records successful payments
   - Updated by payment verification

## How the System Works

### Step 1: Affiliate Creates Customer Referral

**Affiliate Dashboard** (`/affiliate/account`)

- Affiliate (Kaleeswari, AFF001) logs in
- Enters customer details:
  - Firm Name: "ABC Consultants"
  - Contact Person: "Nikila"
  - Email: "nikila@example.com"
  - Phone: "9865421530"

**Backend Process**:

```
1. Creates/Updates affiliate_profiles record
2. Inserts into affiliate_referrals:
   - customer_id: CUS001 (auto-generated by trigger)
   - referral_code: 0CDCCBF1 (from affiliate)
   - referred_name: "Nikila"
   - referred_email: "nikila@example.com"
   - referred_phone: "9865421530"
   - status: 'pending'
3. Sends email (if email provided)
4. Returns link: http://localhost:3000/pricing?ref=0CDCCBF1&cus=CUS001
```

### Step 2: Customer Clicks Link

**URL**: `http://localhost:3000/pricing?ref=0CDCCBF1&cus=CUS001`

**Frontend Process**:

```
1. Pricing page detects ref + cus parameters
2. Stores in localStorage (persists through login/register)
3. Shows green banner: "Referred by affiliate"
```

### Step 3: Customer Registers

**Registration Flow**:

```
1. Customer clicks "Get Started" → "Create Account"
2. Registration page reads ref from callbackUrl
3. Fetches customer data from API:
   GET /api/affiliate/get-customer-data?ref=0CDCCBF1&cus=CUS001
4. Pre-fills form:
   ✅ Name: Nikila (green, read-only)
   ✅ Email: nikila@example.com (green, read-only)
   ✅ Phone: 9865421530 (green, read-only)
5. Customer fills remaining fields and registers
```

### Step 4: Customer Makes Payment

**Checkout Flow**:

```
1. Customer proceeds to checkout
2. Checkout page validates referral:
   - Shows affiliate details in green banner
3. Customer completes payment via Razorpay
4. Payment verification (verify route.ts lines 412-458):
   - Finds affiliate_referral by ref + cus
   - Updates status: 'pending' → 'completed'
   - Records payment_id, order_id, payment_amount
   - Triggers update referral counters
```

### Step 5: Referral Counters Update

**Auto-Update Process** (via database triggers):

```
When affiliate_referrals.status changes:
1. Recalculates total_referrals (count all)
2. Recalculates successful_referrals (status = 'completed')
3. Recalculates pending_referrals (status = 'pending')
4. Updates total_commission (sum of completed commissions)
5. Updates affiliate_profiles record automatically
```

## Important Notes

1. **Referral Code vs Customer ID**:
   - `ref` (referral code) - Permanent, assigned to affiliate (e.g., 0CDCCBF1)
   - `cus` (customer ID) - Auto-increments for each customer (CUS001, CUS002, etc.)

2. **One Affiliate, Multiple Customers**:
   - Kaleeswari (AFF001) has referral code: 0CDCCBF1 (permanent)
   - Each customer gets unique ID:
     - Nikila: CUS001
     - Next customer: CUS002
     - Next customer: CUS003

3. **Auto-fill Only Works for Pending Referrals**:
   - Customer data pre-fills ONLY if status = 'pending'
   - After payment, status changes to 'completed'
   - Completed referrals won't pre-fill (already used)

4. **Email is Optional**:
   - Affiliates can share links via:
     - Email (auto-sent if provided)
     - WhatsApp
     - SMS
     - Manually copy & share

5. **Payment Tracking**:
   - Payment verification automatically:
     - Updates referral status
     - Records payment details
     - Updates counters via triggers
